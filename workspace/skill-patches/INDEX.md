## How to add an entry

1. Author `workspace/skill-patches/<agent>-<slug>.md` from
   `.agents/skills/dev-team/templates/skill-patch.md`.
2. Have the Team Leader order it (R2).
3. Apply the change to the target skill file.
4. Re-run the affected work and capture evidence.
5. Add a row above with status `applied` and the evidence link.
